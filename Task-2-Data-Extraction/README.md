# Task 2: AI-Powered Data Extraction

## Internship

Growfinix AI Internship

## Objective

To extract structured information from unstructured text and convert it into clean JSON format using Python and AI.

## Technologies Used

* Python
* AI API
* JSON

## Project Description

This project processes unstructured customer messages or email text and extracts important information into a structured JSON object.

## Key Features

* Processes unstructured text.
* Extracts relevant customer information.
* Generates structured JSON output.
* Handles data extraction using Python.

## Project Structure

* `main.py` – Main Python program for data extraction.
* `requirements.txt` – Required Python dependencies.
* `tests/` – Test cases for validating the program.

## Execution

Run the Python program using:

```bash
python main.py
```

Install dependencies using:

```bash
pip install -r requirements.txt
```

## Output

The program generates structured JSON containing the extracted information from the input text.

## Learning Outcomes

* Learned to process unstructured text.
* Practiced Python-based data extraction.
* Understood structured JSON output and testing.
